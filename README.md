# SaaS 管理ポータル（モック）

利用しているSaaSのログインURL・ログインID・パスワードを一覧で確認し、目的のサービスをすぐに開くための個人用ポータルのモックです。画面で変更した内容は `services.js` に保存されます。

> [!WARNING]
> **これは架空データ専用のモックです。**
> `services.js` のログインIDとパスワードはすべて動作確認用の架空の値です。画面から編集するときも、架空の値だけを入力してください。
> `services.js` は暗号化されていない平文のファイルです。平文のファイルに認証情報を書くことや、画面上で伏せ字にすることは、認証情報の保護になりません。
> 実際に使うときの保管方式は、モックの確認後に別途決めます。

## 動作環境

- Windows の Microsoft Edge または Google Chrome
- Python・Node.js などの実行環境、Webサーバー、インストールは不要です。

Windows 11 の Google Chrome で動作を確認しています。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面。このファイルをブラウザで開きます |
| `style.css` | デザイン（PCは複数列、スマートフォン幅は1列） |
| `app.js` | 表示・検索・コピー・編集・保存などの処理 |
| `services.js` | サービス情報（架空データ）。画面から保存すると上書きされます |
| `README.md` | このファイル |

これらのファイルは同じフォルダに置いてください。

## 起動方法

`index.html` をダブルクリックします。サービスの一覧が表示されます。

既定のブラウザが Edge・Chrome 以外の場合は、`index.html` を右クリックし、「プログラムから開く」から Microsoft Edge を選びます。

## 使い方

- **検索**：サービス名・カテゴリ・用途・メモを対象に検索します。空白で区切ると、すべての語句を含むものに絞り込みます（例：`GitHub 仕事`）。
- **絞り込み**：カテゴリと「お気に入りのみ」で絞り込めます。検索と組み合わせて使えます。
- **並び順**：「自分で並べた順」「名前」「カテゴリ」から選びます。名前・カテゴリのときは、横のボタンで「↑ 昇順」「↓ 降順」を切り替えます。名前順などは表示だけを並べ替え、`services.js` の順番は変えません。
- **サービスを開く**：ログインURLを新しいタブで開きます。ログインURLは任意です（スマホのPINコードなど、サイトがないものも登録できます）。URLがないカードには、このボタンを表示しません。自動ログインは行いません。ログインIDとパスワードをコピーして、ログイン画面に貼り付けてください。
- **コピー**：ログイン項目（ID・パスワードなど）の値をそれぞれクリップボードにコピーします。結果は画面下部に短く通知されます。
- **伏せ字の表示**：「伏せる」にした項目は、初期状態では伏せ字です。「表示」「隠す」で切り替えます。
- **お気に入り**：☆／★ボタンで切り替えます。
- **編集**：カードの「編集」から、サービス名・カテゴリ・用途・ログインURL・ログイン項目・メモ・お気に入りを変更できます。
- **ログイン項目**：編集画面で、項目の追加（「＋ 項目を追加」）・削除（確認あり）・項目名の変更ができます。メールアドレスが必要なサイトやパスワードだけのサイトなど、サイトに合わせて項目を変えられます。「伏せる」にすると、一覧で伏せ字になります。
- **新規追加**：画面上部の「＋ 新規追加」からサービスを追加します。一覧の最後に追加されます。
- **削除**：編集画面の「このサービスを削除」から削除します。確認が表示されます。
- **並べ替え**：並び順が「自分で並べた順」のとき、カードをドラッグすると、ほかのカードが押しのけられて移動先が空きます。離した位置に移動し、この順番は `services.js` に保存されます。Esc キーや一覧の外で離すと、元の並びに戻ります。

お気に入りの切り替え・編集・追加・削除・並べ替えの内容は、`services.js` に自動で保存されます。

## 保存の仕組み

ブラウザは、セキュリティ上の理由から、画面が自分でファイルを書き換えることを許可していません。そのため、保存先の `services.js` を一度だけ選び、編集を許可する必要があります。

### 初めて保存するとき

1. お気に入りの切り替えや編集の保存をすると、ファイルを選ぶ画面が開きます。`index.html` と同じフォルダにある `services.js` を選びます。
2. 画面上部に「services.js に保存」ボタンが表示された場合は、押します。
3. ブラウザが `services.js` の編集を許可するか確認するので、許可します。

選んだ保存先はブラウザが記憶するため、次回からファイルを選ぶ必要はありません。

### 2回目以降

- 同じタブを開いているあいだは、変更するとすぐに保存されます。
- 次に `index.html` を開いたときは、最初の保存時にブラウザが編集を許可するか確認します。許可すると保存されます。

### 保存できないとき

保存できなかった場合、変更は画面にだけ反映され、画面上部に理由と対処方法が表示されます。

| 表示される理由 | 対処 |
| --- | --- |
| 保存先が選ばれていない | 「services.js に保存」を押し、`services.js` を選びます |
| 書き込みが許可されなかった | 「もう一度保存」を押して許可するか、「変更をダウンロード」で保存します |
| 選んだファイルが `services.js` ではない | 「保存先を選び直す」を押し、正しい `services.js` を選びます |
| 画面を開いた後に `services.js` が変更された | 手で編集した内容を反映するには、F5 キーで再読み込みします（画面での変更は失われます）。画面の変更を残す場合は「変更をダウンロード」を押します |
| 記憶していた保存先が見つからない（フォルダを移動した場合など） | 「保存先を選び直す」を押し、今の場所の `services.js` を選びます |
| ブラウザがファイルの保存に対応していない | 「変更をダウンロード」を押します |

「変更をダウンロード」を押すと、変更後の `services.js` がダウンロードフォルダに保存されます。そのファイルで、ポータルのフォルダにある元の `services.js` を置き換え、F5 キーで再読み込みしてください。会社のポリシーでブラウザからのファイル書き込みが禁止されている場合も、この方法で保存できます。

保存していない変更があるままタブを閉じようとすると、確認が表示されます。

### 保存される内容

- 変更したサービスの、変更した項目だけが書き換わります。ほかのサービスや、画面に表示していない項目はそのまま残ります。
- 保存すると `services.js` は整形し直されます。手で書いたコメントは、先頭の説明コメントに置き換わります。

## services.js の形式

サービスの追加・削除は画面からできます。`services.js` をメモ帳などで直接編集する場合は、編集後にブラウザで F5 キーを押して再読み込みしてください。

`window.SERVICES = [` と `];` のあいだに、次の形式で項目を書きます。項目と項目の間はカンマで区切ります。画面から保存できるように、`[ ]` の中は JSON の形式で書いてください（キーと文字列はダブルクォートで囲む、最後の項目の後ろにカンマを付けない）。

```js
  {
    "id": "example-personal",
    "name": "Example",
    "category": "開発",
    "accountLabel": "個人用",
    "url": "https://example.com/login",
    "fields": [
      { "label": "メールアドレス", "value": "demo@example.invalid", "secret": false },
      { "label": "パスワード", "value": "DEMO_ONLY_123!", "secret": true }
    ],
    "memo": "メモ",
    "favorite": false
  }
```

| 項目 | 説明 |
| --- | --- |
| `id` | 必須。ほかの項目と重複しない文字列。同じサービスの個人用・仕事用は別の `id` にします（例：`github-personal`、`github-work`）。画面からは変更できません |
| `name` | サービス名 |
| `category` | カテゴリ。ここに書いた値が絞り込みの選択肢になります |
| `accountLabel` | アカウントの用途（個人用・仕事用など） |
| `url` | ログインURL（任意）。`http://` か `https://` で始まるURLのみ開けます |
| `fields` | ログイン項目の一覧（値は架空のものに限る）。`label` は項目名、`value` は値、`secret` は `true` なら伏せ字で表示 |
| `memo` | メモ |
| `favorite` | お気に入り。`true` または `false` |

- 一覧に表示される順番は、`services.js` に書いた順番です。
- `fields` の代わりに、以前の形式の `loginId`（ログインID）と `password`（パスワード）も使えます。この場合は「ログインID」「パスワード（伏せ字）」の2項目として表示します。画面で編集して保存すると、そのサービスだけが `fields` 形式に書き換わります。

- `id` がない項目や、`id` が重複している項目は表示しません。表示しなかった件数は、件数表示の横に出ます。
- `services.js` が見つからない場合や書式が誤っている場合は、画面にエラーメッセージを表示します。

## 認証情報の扱い

- 認証情報（ID・パスワードなど）は、`localStorage`・`sessionStorage`・IndexedDB・ログ・URLに保存しません。開いているタブのメモリ上と `services.js` だけで扱います。
- 保存先を記憶するため、IndexedDB には `services.js` の場所（ファイルハンドル）だけを保存します。この記憶は、同じPCのブラウザで開いたほかのHTMLファイルからも参照できます。
- 外部のサーバーには何も送信しません。
- データの文字列は `textContent` で描画し、HTMLとして解釈しません。
- リンクはHTTP/HTTPSのURLだけを許可し、新しいタブには `rel="noopener noreferrer"` を付けています。
